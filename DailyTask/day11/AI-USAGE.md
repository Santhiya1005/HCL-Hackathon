- Review: Check encapsulation, null handling, and collection safety.
- Verification: Compile and test the getters and subject list.

- Prompt: Create a Java service to add, find, and list students.
- Review: Check duplicate IDs, returned collections, and exception handling.
- Verification: Test adding students, finding an existing ID, and adding a duplicate.

- Review: Check generic types, null handling, and whether returned lists expose internal state.
- Verification: Save two students, find one, and print the repository list.
